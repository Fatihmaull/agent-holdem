# Card art

Rendered to PNG from the SVG deck at https://github.com/saulspatz/SVGCards
(deck variant `Vertical2`: traditional vertical index, two-colour suits).

Placed in the public domain by Saul Spatz. The court-card and joker figures in
that deck are from Byron Knoll's public-domain playing card set
(https://commons.wikimedia.org/wiki/Category:Playing_cards_set_by_Byron_Knoll);
the back pattern is from openclipart.org.

No attribution is legally required. This file exists so the next person knows
where the art came from and can re-render it rather than guess.

Source is 210x315 SVG; these are 420x630 PNG, which is 5x the 84px the table
draws a card at. `CARD_RATIO` in src/components/table-art.tsx must match.
